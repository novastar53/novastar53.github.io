Interactive probability explorer: Altair vs GenStudio¶

This is a throwaway comparison notebook. The master article is unchanged. Both charts use the same bias and sample-size sliders, the same probabilities, and the same article palette. Neither uses pandas. They can be exported as standalone interactive HTML.

Install the extra libraries once in your environment (uv add altair genstudio).

import sys
from pathlib import Path

sys.path.insert(0, str(Path.cwd()))
from altair_explorer import build_chart as build_altair_chart
from genstudio_explorer import build_chart as build_genstudio_chart

What to compare¶

Styling and typography; slider responsiveness; vertical spacing (especially whether the next Markdown cell is obscured); exported standalone HTML; and the readability of the Python source. Try p=0.8, N=6, p=0.5, N=20, and p=0.6, N=30.
